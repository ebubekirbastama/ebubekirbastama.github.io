ŞABLON STÜDYOSU

JSON şablonu anında önizle, kendi HTML tasarımını okunabilir şablona çevir.

Bu sayfa ana yayın sayfasından bağımsız çalışır — kamera bağlamadan, yayın başlatmadan şablon tasarımını görebilir ve dışa/içe aktarabilirsin.

1) JSON Config Yükle

Anlık Önizleme

Yayın sayfasındaki "⬇ Şablonu Dışa Aktar" ile indirdiğin .json dosyasını buraya yükle — tasarım aşağıda anında görünür.

2) HTML Tasarımını Yükle

HTML → JSON

Kendi tasarladığın .html dosyasını yükle; aşağıdaki kurala uyan elementleri otomatik olarak okunabilir bir yayın şablonuna (JSON) çevirir.

⬇ Örnek HTML Şablonunu İndir

HTML Kuralı (Kısa)

  1. Tasarımını 1920×1080 piksel sabit boyutlu, position:relative bir kapsayıcı içine yap ve ona data-stage ekle.
  2. Her öğeyi position:absolute ile yerleştir ve data-layer-type ver: camera, text, ticker, image veya custom.
  3. Kamera kutularına sırayla data-cam-index="0", "1"… ver.
  4. Dinamik metinlere data-field ver: title, subtitle, ticker, guest1Name, guest1Title, socials vb. data-field yoksa element metni sabit ("custom") metin olarak alınır.
  5. Yazı boyutu/rengi/kalınlığı CSS'ten (font-size, color, font-weight) otomatik okunur.

Emin değilsen önce örnek şablonu indirip onun üzerine kendi tasarımını uygula.
